Load emulator

Move the slider. Each bar shows how full one part is. This is an estimate from the numbers below, not a load test. Each number says where it comes from: a file in the repo, a provider limit, or an assumption.

How the estimate worksLoad on a part = requests per second × calls per request. Wait time grows as the part fills up (time ÷ (1 − use)). Requests in flight = requests per second × end-to-end time (Little's Law). Real systems also slow down from locks, cold starts and noisy neighbors: a load test finds those.
